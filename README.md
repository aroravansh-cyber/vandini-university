# 🎓 Vandini University Website

A modern and responsive **fictional university website** built as a frontend web development project.

> ⚠️ Vandini University is a fictional institution created for educational and portfolio purposes.

## 🌐 Live Demo

🔗 https://vandiniuniversity.netlify.app/

## ✨ Features

- 🏫 University landing page
- 📚 Courses & programs section
- 👨‍🎓 Student-focused sections
- 🏛️ About the university
- 📞 Contact section
- 📱 Responsive design
- 🎨 Modern UI

## 🛠️ Tech Stack

- HTML5
- CSS3
- JavaScript

vandini-university/

## 🎯 Purpose

This project was created to practice **frontend development, responsive design, UI/UX, and website structure.**
